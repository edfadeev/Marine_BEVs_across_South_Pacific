# Marine BEVs across the South Pacific

This repository contains analysis scripts and workflow notes for studying marine bacterial extracellular vesicles (BEVs) and paired cellular fractions across the South Pacific transect.

## Related publication

The repository is linked to the following publication:

- https://academic.oup.com/ismej/article/20/1/wrag171/8722774

## Repository contents

- `/R/` — R scripts for data processing, protein annotation integration, taxonomic summaries, abundance analyses, and figure/table generation.
- `/data/` — metadata files used by the analyses (for example, `samples_metadata.txt`).
- `/anvio_wokrflow/` — anvi’o/HPC workflow configuration and shell scripts for metagenome co-assembly and downstream protein annotation steps.
- `/download_data_from_Zenodo.R` — helper script to download and unpack raw/source datasets from Zenodo into `data/raw/`.

## Main analysis components

- **Particle and cell abundance processing**: `process_NTA.R`, `process_FCM.R`, and `Abundance_cells_BEVs.R`
- **Protein table construction and annotation merging**: `protein_table.R`, `protein_annotation.R`, `protein_taxonomy.R`, `protein_localization.R`
- **Proteome-level comparisons and summaries**: `BEVs_proteome.R`, `cellular_proteome.R`, `proteomic_overview.R`, `metagenomes_tax_composition.R`, `TonB_proteins.R`

## Notes

- Scripts are organized as an analysis workflow and may depend on outputs generated by earlier steps.
- The `anvio_wokrflow` directory reflects the original project folder naming used in this repository.
